# CYBERSEC RANGE 830 V3.5 Demo · 测试用例（权威来源）

> 唯一真实来源：本文档为测试步骤的权威定义；`TEST-EXECUTION-TRACKING.csv` 仅记录执行状态。
> 模式：AAA（准备 → 执行 → 断言）。优先级：P0 阻塞 / P1 严重 / P2 高 / P3 中 / P4 低。
> 环境：Windows + Edge（headless）· `node server.js --port 7132` · 演示数据（Mock）。

## 通用前置条件

- G1：demo 服务已启动（`npm run dev`，端口 7132）。
- G2：已通过 SSO 登录（`sessionStorage cr-auth=1`）。
- G3：浏览器视口 1920×1080，默认深色主题。
