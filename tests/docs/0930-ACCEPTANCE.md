# 930 Demo 验收清单

## 通用

- 登录后进入角色总览，不再进入传统态势大屏。
- 可以在训练用户、监管用户、开发者与企业用户之间切换。
- 每个角色只显示自己的核心任务入口，共享数据引擎、场景与任务库、资源接入。
- 所有页面必须明确这是隔离环境内的演示数据，不把 Mock 描述为真实生产结果。

## 训练用户

1. 进入训练数据消费。
2. 查看数据卡中的来源、质量、隐私、用途、许可证和偏差。
3. 创建受控消费记录。
4. 未确认使用条件时不能创建记录。
5. 新记录展示数据版本、模型、用途、消费方式和待回填效果状态。

## 监管用户

1. 进入监管评测工作台。
2. 查看冻结条件下的任务队列、结果确认和报告闸门。
3. 待确认项未办结时，评测报告保持禁用。
4. 任务结果可以回指证据摘要。

## 开发者与企业用户

1. 进入数据生产工作台。
2. 查看 AI 原生生产链和现有生产批次。
3. 创建批次时设置数据目标、任务配方、Agent、Roll 数、并发和隐私级别。
4. 启动后生成运行中批次。
5. 页面明确越权、逃逸、敏感泄露和预算异常会阻断运行。

## 数据引擎

- 展示正式数据版本及来源 Run、轨迹数、质量、隐私、用途和消费次数。
- 展示结构证据、隐私用途、消费效果三类门禁。
- 可以进入 V3.9 历史数据资产页面。

## 兼容性

- 旧训练调度页面仍可从训练数据消费页进入。
- 原靶场大厅、接入网关、任务执行和结果确认功能保持可访问。
- 深色和浅色主题均可用。
