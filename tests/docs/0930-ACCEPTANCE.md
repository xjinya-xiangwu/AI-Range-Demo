# 930 Demo 验收清单

## 通用

- 登录后按账号身份直接进入对应产品空间，不出现公共角色总览。
- 演示身份切换只放在左下角头像菜单中；切换后进入另一套首页和导航。
- 研究员、监管、开发者与企业用户拥有独立导航，不显示无关一级模块。
- 所有页面明确这是隔离环境内的演示数据，不把 Mock 描述为真实生产结果。

## 研究员空间

1. 登录后进入训练任务列表。
2. 左侧按场景拆分为训练任务、版本对比和私有数据。
3. 新建训练任务时选择基础模型、授权数据版本、固定基准、训练方式和资源。
4. 运行中任务可查看实时指标，完成后可查看模型与数据产物。
5. 页面突出运行中、排队、待评估和本周新版本状态。
6. 可以选择任意两个模型或智能体版本，在同一冻结基准下比较能力、安全和成本。
7. 页面展示实验室私有轨迹、专家偏好和失败恢复样本在训练配方中的占比及对同基准结果的贡献。
8. 新建训练任务时可选择受控挂载的实验室私有数据版本。

## 监管空间

1. 登录后进入评测任务列表。
2. 左侧业务导航只有评测任务。
3. 创建任务后可查看冻结条件、运行状态、争议证据和报告闸门。
4. 待确认项未办结时，评测报告保持禁用。
5. 不显示训练、数据集、生产管线或资源接入入口。

## 开发者与企业空间

1. 登录后默认进入企业“总览”，而不是生产任务列表。
2. 一级导航包含总览、数据资产、生产任务、标注工作台和 Agent 与环境。
3. 总览以“数据飞轮”展示模拟靶场与攻防任务、AI 预标注、人工复核、训练消费和测试回流。
4. 总览的数据血缘明确展示当前训练任务与测试任务，并说明各数据版本如何服务 RL、CPT 和 DPO 训练。
5. 总览至少展示 4 条正在生产的 70+ steps 长链路轨迹生产管线，包含当前/目标步骤、阶段分布、调用量、实时质量和目标数据集。
6. 数据资产按攻击轨迹、防御响应、漏洞样本、工具调用、安全边界、评测样本、多模态观测和专家标注分类。
7. 生产任务定义目标数据集、场景、Agent、环境、Roll、预算、停止条件、质量和数据安全规则。
8. 所有需要人工判断的结果标签、ATT&CK 映射、失败原因、风险边界和敏感信息进入标注工作台。
9. AI 辅助标注必须展示建议标签、置信度、命中规则和支持证据，不使用隐藏思维链作为依据。
10. 人工可确认签名、退回补证据或将样本隔离；高风险样本支持双人复核。
11. 越权、逃逸、敏感泄露和预算异常会阻断生产任务。

## 角色边界

- 研究员直接访问企业或监管路由时，返回训练任务。
- 监管用户直接访问训练、数据集或网关路由时，返回评测任务。
- 企业用户直接访问训练或监管路由时，返回攻防数据生产工作台。
- 个人与权限对三类身份均可访问。

## 兼容性

- 原训练实时监控、评测执行、结果确认、场景模板和接入网关作为角色流程中的二级能力保持可访问。
- 深色和浅色主题均可用。
