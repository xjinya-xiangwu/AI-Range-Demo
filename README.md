# CYBERSEC RANGE 930 Demo

基于原 830 V3.9.2 Demo 增量建设的 930 三类用户版本。

## 本分支新增

- **训练用户**：授权数据集、数据卡、隐私级别、受控消费和效果回传入口。
- **监管用户**：复用原测试任务、结果确认和报告闸门，重命名为监管评测工作台。
- **开发者与企业用户**：任务配方、Agent / 环境接入、批量 Roll、自动验证和数据交付。
- **数据引擎**：统一展示轨迹、证据、质量、隐私、数据版本、消费与效果。
- **AI 原生闭环**：930 先编排现有模板与批准组件，不自动生成未知攻击能力。

## 运行

```bash
npm run dev
```

默认地址：`http://127.0.0.1:7100`。演示账号已预填，点击 SSO 登录即可。

## 验证

```bash
npm test
```

静态检查覆盖 930 新路由、三类用户入口、数据隐私和 AI 生产闭环。浏览器验收见 `tests/docs/0930-ACCEPTANCE.md`。

## 产品边界

这是产品交互 Demo。任务、数据和运行状态为演示数据，不连接真实生产网络，不提供无约束攻击能力。正常流程可以自动编排；高风险动作、环境逃逸、敏感泄露、证据冲突和跨用途数据流转必须阻断或人工处理。
