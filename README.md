# CYBERSEC RANGE 网安攻防演练场 · 830 V3.5 Demo

830 交付版演示原型：态势感知首页大屏 · 靶场测试真实链路 · 训练任务 Mock 演示。

## 运行

```bash
npm run dev        # 零依赖静态服务器，默认 http://127.0.0.1:7100
node server.js --port 7132 --host 127.0.0.1   # 指定端口
```

打开后进入 SSO 登录页（演示账号已预填，点击「SSO 登录」即可进入）。

## 信息架构（PRD V3.5）

```
态势感知            首页大屏（指标带 / 拓扑轮播 / 事件流 / 监控融合 / 预警条）
操作中心
├─ 测试任务         任务中心（创建向导 + 运行中队列 + 已完成列表）· 靶场大厅 · 结果确认（研判+报告+分析）
├─ 训练任务         任务中心（5 步向导 + 双列表）· 实时监控（wandb 风）· 模型中心
└─ 实战演练场       占位（研发中）
资源中心
├─ 数据中心         数据量仪表盘 + 轨迹/风险数据集 + 测试题库管理
├─ 接入网关         外部模型/Agent · 密钥管理 · 接入方式 · 接入校验 · 会话管理 · 接口中心
└─ 用户设置         个人中心 · 监控中心 · 工具集市（占位）
账号体系            SSO 登录 / 注册 / 忘记密码（侧边栏之外）
```

## 技术说明

- 零依赖：原生 HTML/CSS/JS（hash 路由 SPA），Node 内置静态服务器。
- 主题：暖纸 / 暖夜双主题 token 体系，默认深色驾驶舱。
- QA：`tests/docs/01-TEST-CASES.md`（82 条 AAA 用例）+ `tests/e2e/qa-suite.js`（puppeteer-core 自动化执行，需本机 Edge）。
