# CYBERSEC RANGE 930 Demo

面向三类用户的角色化产品 Demo，基于原 830 V3.9.2 交互资产重构。

## 当前产品空间

- **研究员空间**：拆分为训练任务、版本对比和私有数据三个场景页面；任务首页只负责创建、运行和结果入口。
- **监管空间**：只保留评测任务与个人权限；从任务进入执行、证据确认和报告。
- **开发者与企业空间**：围绕攻防数据生产组织为总览、数据资产、生产任务、AI 辅助标注工作台和 Agent 与环境接入；总览展示训练与测试任务数据血缘和多条正在生产的 70+ steps 长链路轨迹生产管线，标注工作台集中处理所有人工判断。

共享的任务执行、轨迹、证据、数据版本、权限和审计仍作为底层能力复用，但不再作为所有角色都能看到的公共一级导航。Demo 身份切换位于左下角头像菜单。

## 运行

```bash
npm run dev
```

默认地址：`http://127.0.0.1:7100`。演示账号已预填，点击 SSO 登录即可。

## 验证

```bash
npm test
```

静态检查覆盖角色首页、独立导航、路由边界、数据集、生产管线和安全说明。浏览器验收见 `tests/docs/0930-ACCEPTANCE.md`。

## 产品边界

这是产品交互 Demo。任务、数据和运行状态为演示数据，不连接真实生产网络，不提供无约束攻击能力。正常流程可以自动编排；高风险动作、环境逃逸、敏感泄露、证据冲突和跨用途数据流转必须阻断或人工处理。
